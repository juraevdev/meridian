# Meridian

Raqamli infratuzilmani — loyihalar, ilovalar, domainlar, serverlar va integratsiyalarni — bitta joydan ko‘rish va boshqarish platformasi.

## Ishga tushirish

```bash
npm install
npm run dev
```

Brauzerda `http://localhost:5173` (yoki band bo‘lsa `5174`) ochiladi.

## Ma’lumotlar

Demo yo‘q. Ma’lumotlarni o‘zingiz kiritasiz — brauzer **localStorage** da saqlaydi.

1. **Projects** → yangi loyiha
2. Keyin Apps / Domains / Servers / Integrations
3. Edit / Delete bilan tahrirlash

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- React Router
- Framer Motion
- Lucide icons
